Reader test fixtures
====================

- `book.epub`, `book.mobi`, and `book.azw3` were generated from the text
  `Hello from ODT` with Calibre's `ebook-convert` command.
- `book.odt` was generated from the same disposable text with LibreOffice Writer.
- `testfile.rar3.cbr` comes from
  https://github.com/ssokolow/rar-test-files/blob/master/build/testfile.rar3.cbr
  (CC0). SHA-256:
  `6598d1c5f7accfeefbda2bf03f934181486a42ea06a4d322d6016410d1a89cc1`.

All readers use copies in the target app's disposable cache directory.
